## Мотивация

Главная причина создания этого репозитория:
- Собрать в одном месте **все русскоязычные** доклады про iOS разработку

А также:

- Разбивка по темам
- Разбивка по датам
- Open Source концепция, где каждый сможет добавлять новые доклады и принимать участие в структуре репозитория
- Статистика русскоязыного iOS сообщества в целом

## Как это собирается

README генерируется из [data/talks/](data/talks/) (по файлу на год) — не редактируйте его напрямую.

```bash
python3 scripts/fetch.py        # обойти каналы, собрать пул видео
python3 scripts/classify.py     # эвристический триаж: кандидаты / отсев
python3 scripts/enrich.py       # добрать описания и даты у кандидатов
python3 scripts/review.py       # выгрузить инбокс в data/review.md
python3 scripts/promote.py ID --category swift   # забрать доклад в базу
python3 scripts/build_readme.py # пересобрать README
```

Подробности — в [CONTRIBUTING.md](CONTRIBUTING.md).
